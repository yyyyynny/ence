# 검토 대기 목록

여기 적는 것은 결론이 아니라 **다음에 누가 봐도 바로 판단할 수 있게 남겨 두는 안건**이다.
지금 당장 정하지 않기로 한 것들이라, "이렇게 하자"가 아니라 "무엇을 판단해야 하는가"만 적는다.

---

## 1. 이스터에그의 하트 이모지

**지금 상태**: `js/app.js:734`. 로고를 누르면 뜨는 화면이 예전엔
「💖 깜짝이야! 💖」였는데, 지금은 「깜짝이야!」만 남고 하트 두 개가 없다.

**왜 이렇게 됐나**: 2026.09.02 재디자인에서 "화면에 이모지를 하나도 안 남긴다"는
기준을 예외 없이 적용했고, 그 과정에서 하트도 같이 빠졌다. 같은 작업에서 이
이스터에그는 "AI가 절대 못 만드는, 가장 사람 냄새 나는 자리"로 따로 분류돼
로고 자체와 농담 문구는 지키기로 했었다 — 하트만 별도로 다시 볼지는 그때
정하지 않았다.

**판단할 것**: 이모지 0이라는 기준을 여기도 예외 없이 적용하는 게 맞는지,
아니면 이 자리는 성격이 달라 하트가 있는 쪽이 원래 의도(깜짝 이벤트의 장난기)에
더 맞는지. 코드만 봐서는 답이 안 나오고, 실제로 화면에서 본 인상으로 정할 문제다.

## 2. 연속·맞음·틀림 통계를 계속 띄울지

**지금 상태**: 화면 맨 위, 항상 보이는 자리.
- 마크업: `index.html:101-109`
- 갱신: `js/app.js:1748-1752`
- 점수 계산: `js/app.js:1085`(오답 시 연속 초기화), `:1547`(정답 시 증가), `:1554`(오답 시 증가)

**판단할 것**: 이 통계가 학습에 실제로 도움이 되는지, 아니면 부담(특히 "틀림"
숫자가 계속 쌓이는 걸 보는 것)으로 작용하는지는 사용자가 써 보며 판단할 문제라
이번엔 손대지 않았다. 고려해 볼 방향은 그대로 두기 / 오답노트처럼 원할 때만
열어 보게 하기 / 아예 빼기 — 지금은 어느 쪽도 정하지 않은 상태다.
